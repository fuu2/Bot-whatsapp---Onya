ONYA - PENGINGAT PRESENSI / JADWAL PRIBADI
24 September 2026

PEMBARUAN TERBARU

1. Hentikan bot dengan Ctrl+C.
2. Ekstrak paket ke folder terpisah, lalu salin seluruh isi src ke
   D:\Project\bot-whatsapp\src dan pilih Replace untuk file yang sama.
   File baru reminder-time.js dan reminders.js wajib ikut disalin.
3. Pertahankan .env, folder sesi login, dan folder data yang sudah ada.
4. Pengaturan waktu opsional pada .env: REMINDER_TIMEZONE=Asia/Jakarta
   Jika belum ditambahkan, bot otomatis memakai WIB.
5. Jalankan dari folder proyek:
   cd D:\Project\bot-whatsapp
   npm.cmd start
6. Pastikan [BOT-REMINDER v1] muncul. Tunggu bot aktif, lalu kirim perintah
   melalui chat pribadi ke nomor Onya. Tidak perlu npm install ulang.

BOT HARUS TETAP MENYALA

Jadwal disimpan dalam data/reminders.json dan bertahan setelah restart.
Jika bot/laptop mati atau sleep, pesan tidak dapat dikirim pada waktunya.
Pengingat sekali yang terlewat dikirim saat bot tersambung lagi dengan
keterangan terlambat. Jadwal harian yang tertinggal beberapa hari hanya
mengirim kejadian terlewat paling baru, lalu melanjutkan jadwal berikutnya.
Penjadwal memeriksa tiap detik; pengiriman dapat terlambat karena koneksi.

Kegagalan pengiriman dicoba ulang sampai tiga kali dengan jeda satu menit.
Jika proses mati saat kirim, status pengiriman terputus terlihat pada
!pengingat. Periksa apakah pesannya sudah masuk, lalu hapus/buat ulang
jadwal bila perlu. Tidak ada jaminan pengiriman tepat sekali saat gangguan.

WITA: REMINDER_TIMEZONE=Asia/Makassar
WIT: REMINDER_TIMEZONE=Asia/Jayapura
Perubahan zona bawaan tidak menggeser pengingat yang sudah dibuat.
Gunakan satu proses bot per folder data. Cadangkan data sebelum pindah server.

PANDUAN FITUR SEBELUMNYA

ONYA - PEMUTAR VIDEO DAN AUDIO LANGSUNG DI WHATSAPP
23 September 2026

PEMBARUAN DARI DOWNLOADER VERSI SEBELUMNYA

1. Hentikan bot dengan Ctrl+C.
2. Ekstrak ZIP ke folder terpisah. Salin seluruh isi folder src ke
   D:\Project\bot-whatsapp\src dan pilih Replace untuk file yang sama.
3. Tambahkan atau ubah DOWNLOAD_AS_DOCUMENT=false dalam file .env aktif.
   Jangan menimpa .env dengan .env.example.
4. Jalankan npm.cmd start dari D:\Project\bot-whatsapp.
5. Pastikan ada [BOT-DOWNLOADER v3] dan mode pemutar video/audio WhatsApp.
6. Kirim ulang perintah downloader; pesan dokumen lama tidak berubah.

Pembaruan tampilan ini tidak memerlukan instalasi npm/yt-dlp ulang.
VIDEO_AS_DOCUMENT hanya untuk !tovideo; downloader memakai DOWNLOAD_AS_DOCUMENT.
Audio dikirim sebagai audio biasa dengan tombol putar, bukan voice note.
Video diubah ke H.264/AAC; rasio tampilan dipertahankan. Konversi memakai CPU
selama proses. Batas ukuran, waktu, dan pembersihan file sementara tetap berlaku.
Browser yang digunakan akan melaporkan dukungan codec pada baris [BOT-CODEC].
Jika video/audio gagal terkirim, sertakan baris tersebut dan log error pengiriman.

PEMBARUAN LENGKAP / MEMASANG DOWNLOADER PERTAMA KALI

1. Hentikan bot dengan Ctrl+C di terminal.
2. Cadangkan kode yang pernah kamu edit sendiri.
3. Ekstrak ZIP ini ke folder terpisah.
4. Salin seluruh isi folder src, scripts, test, serta package.json dan README.md
   ke D:\Project\bot-whatsapp. Gabungkan folder dan pilih Replace untuk file sama.
   Pastikan src\download-url.js ikut disalin: file ini baru.
   Pertahankan .env, node_modules, tools, dan sesi login lama.
5. Jalankan di PowerShell dari folder proyek, bukan dari folder src:

   cd D:\Project\bot-whatsapp
   node scripts/setup-downloader.js
   npm.cmd run doctor
   npm.cmd start

6. Pastikan log startup memuat:
   [BOT-DOWNLOADER v3] Pengiriman hasil: pemutar video/audio WhatsApp.
   [BOT-BROWSER] Menggunakan: ...brave.exe
7. Tunggu Onya aktif. Kirim !downloader dari nomor WhatsApp lain.

Tidak perlu npm install ulang jika dependensi bot versi sebelumnya sudah terpasang.
Gunakan Node.js 22 atau lebih baru. Pemasang memperbarui yt-dlp resmi ke folder
tools dan memeriksa checksum. Python tidak diperlukan di Windows.
Jika YTDLP_PATH di .env menunjuk lokasi lain, perbarui executable di lokasi itu
atau kosongkan YTDLP_PATH= agar bot memakai file dalam folder tools.

PERINTAH

!fb URL_VIDEO        Video Facebook menjadi MP4
!tt URL_VIDEO        Video TikTok menjadi MP4
!ytmp4 URL_VIDEO     Video YouTube atau Shorts menjadi MP4
!ytmp3 URL_VIDEO     Audio video YouTube menjadi MP3
!ttaudio URL_VIDEO   Audio video TikTok menjadi MP3
!downloader         Panduan lengkap dan alias perintah

Ganti URL_VIDEO dengan link asli dari aplikasi, tanpa tanda kurung.
Satu tautan per perintah. Hasil dikirim sebagai video/audio dengan pemutar.
Jika DOWNLOAD_AS_DOCUMENT=true, hasil dikirim sebagai dokumen.
Audio MP3 dikonversi 128 kbps. Gunakan URL video TikTok yang memiliki suara,
bukan halaman profil atau kumpulan sound. Batas bawaan tiap file 16 MB,
durasi sumber 600 detik jika diketahui, dan satu unduhan sekaligus.
Waktu mengunduh plus konversi maksimal 180 detik; pengiriman WhatsApp terpisah.
File sementara dihapus setelah selesai/gagal dan saat bot dihentikan normal.

PERBAIKAN FACEBOOK

Versi ini menerima lebih banyak bentuk link bagikan dan postingan video.
Host mobile tidak dipaksa kembali ke www saat redirect. Cookie pengunjung
disimpan sementara selama resolusi link; bot juga membaca alamat video dari
metadata halaman. Bot tidak mengambil cookies login dari Brave.

Jika Facebook tetap gagal, coba URL lengkap video dari browser, misalnya
facebook.com/reel/ID atau facebook.com/watch/?v=ID.
Kirim URL asli yang gagal dan log terbaru untuk pemeriksaan lebih lanjut.
Screenshot error saja belum menunjukkan URL yang digunakan.
Tautan yang meminta login, video privat, playlist, album foto, dan live
belum didukung. Video publik juga dapat ditolak oleh situs sumber.

BRAVE

Deteksi otomatis Brave dan perbaikan ID/pengiriman media v2 sudah termasuk.
CHROME_PATH yang benar tetap dipakai. Jika salah, perbaiki atau kosongkan
CHROME_PATH= dalam .env untuk deteksi otomatis. Untuk lokasi khusus, buka
brave://version dan salin Executable Path ke CHROME_PATH.
Nama bot memakai BOT_NAME=Onya. Pengaturan .env yang lain tetap dapat dipakai.

PENGUJIAN

18 tes pengingat mencakup waktu WIB/WITA/WIT, penyimpanan, restart, jadwal
sekali/harian, pembatalan, kepemilikan chat, retry, dan kegagalan penulisan.
Pengiriman WhatsApp disimulasikan; penerimaan nyata perlu dicoba di akunmu.

86 pengujian lulus di Linux dengan Node.js 24.19.0 dan yt-dlp 2026.08.19.
yt-dlp dan FFmpeg asli diuji memakai server media lokal: gabungan MP4+audio,
MP3 dari trek audio, MP3 dari video bersuara, dan penolakan MP3 dari video tanpa suara.
Normalisasi MP4 diperiksa: H.264 Main/yuv420p, AAC, 30 fps, portrait, dan faststart.
Pengujian pengiriman memeriksa opsi video/audio biasa serta mode dokumen opsional.
Tes resolver memeriksa redirect mobile, metadata, cookie sementara, serta loop.
Tes ini tidak membuktikan akses ke video tertentu di situs sumber.
Pengiriman WhatsApp disimulasikan; runtime Windows dan penerimaan WhatsApp
perlu dicoba pada laptop/akun pengguna.

Untuk menjalankan tes: npm.cmd test
Tes CLI dilewati jika executable lokal yt-dlp belum dipasang.
Baca README.md untuk pemasangan dari awal, konfigurasi, dan struktur kode.
